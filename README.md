# skillsheetnohensyuu

スキルシートを編集・管理するためのプロジェクトです。

## 目的

このリポジトリでは、スキルシートに関するファイルや変更内容を管理します。

## 今後やること

- スキルシートの内容を整理する
- 必要なファイルを追加する
- 変更した内容を保存して管理する

## 要員紹介文Webアプリ

`web/` にPDFから要員紹介文を作成する「紹介文スタジオ」を追加しました。
正社員・契約社員・BP（協力会社）の選択、BP原文の参照、元単価への10万円加算、紹介文の編集・コピーに対応しています。

起動・API設定・品質確認の手順は [web/README.md](web/README.md) を参照してください。
PDFの自動入力にはOpenAI APIの設定と利用料が必要です。参考PDFや個人情報はリポジトリに含めていません。
